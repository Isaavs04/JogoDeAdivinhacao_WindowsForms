# JogoDeAdivinhacao_WindowsForms
Jogo de adivinhar números feito no WindowsForms

## ✦ Sobre
Projeto pessoal realizado para melhorar a compreensão de tratamneto de erros e aleatorização de números no C#, junto com uma das coisas que mais gosto: a programação de jogos
